# POS Backend — Sistem Kasir

Backend aplikasi kasir (point of sale) berbasis Laravel 10 untuk transaksi retail, katalog produk, dan cetak struk. Cocok untuk outlet kecil hingga menengah.

## Fitur

- Manajemen katalog produk & kategori
- Transaksi penjualan kasir dengan kembalian
- Cetak struk transaksi
- Mode dark / light untuk tampilan kasir
- Integrasi printer Bluetooth via browser
- Laporan transaksi harian & bulanan

## Teknologi

- [Laravel 10](https://laravel.com)
- [Filament PHP](https://filamentphp.com) (admin panel)
- [Sanctum](https://laravel.com/docs/sanctum) (API authentication)
- Tailwind CSS (via CDN pada halaman kasir)
